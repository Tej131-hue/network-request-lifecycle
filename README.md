# 🌐 Network Request Lifecycle Simulation Tool

## Overview
This project simulates the steps involved when a user accesses a website, from DNS lookup to server response.

## How It Works
1. User enters a URL
2. DNS lookup is simulated
3. IP address is resolved
4. HTTP request is sent
5. Server processes the request
6. Response is returned

## Tech Used
- Python
- Networking fundamentals
- Simulation logic
